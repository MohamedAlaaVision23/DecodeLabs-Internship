# 🤖 DecodeBot Chatbot

A simple rule-based chatbot built using Python during my internship training at Decode Lab.

## 📌 Project Overview
DecodeBot is a beginner-friendly chatbot designed to handle basic user conversations using rule-based logic.

The chatbot can:
- Respond to greetings and common questions
- Provide current time and date
- Motivate users with simple responses
- Store and recall the user's name (basic memory feature)
- Handle unknown inputs gracefully

---

## 🚀 Features
✅ Greeting responses  
✅ Date & time functionality  
✅ User name memory  
✅ Randomized chatbot responses  
✅ Rule-based conversation system  
✅ Simple and clean Python implementation
